Política de privacidad de JARVIS

JARVIS es una aplicación de uso exclusivamente personal: solo la usa su propietario, en su propio ordenador.

Qué datos usa

  • Google Calendar: lee los eventos para responder preguntas sobre la agenda y crea eventos solo cuando el propietario lo pide y lo confirma.
  • Gmail: solo lectura, para resumir los correos recibidos. Nunca envía, modifica ni borra correos.

Dónde se guardan

Los datos se leen directamente de Google y se procesan en el propio ordenador. No se almacenan en ningún servidor, no se comparten con terceros, no se venden y no se usan para publicidad. El permiso de acceso se guarda solo en ese ordenador y puede revocarse en cualquier momento desde myaccount.google.com/permissions.

Uso de datos de las API de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
